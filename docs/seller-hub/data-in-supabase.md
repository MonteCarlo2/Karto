# Что Seller Hub хранит в Supabase, а не в браузере

Принцип: всё, что должно быть одинаковым на всех устройствах и переживать перезагрузку, лежит в Supabase. Браузер хранит только то, что не страшно потерять (последний снимок каталога как раньше, временное состояние экрана).

Миграция `supabase/migrations/20261016_seller_hub_agents_cache.sql` (применена 16.10.2026, только новые таблицы, RLS включён, «Автоотзывы» не затронуты):

| Таблица | Для чего | Кто пишет |
|---|---|---|
| `seller_hub_data_cache` | Серверный кэш ответов WB с узкими лимитами: статистика рекламы (10 мин), запросы и кластеры (30 мин), рекомендованные ставки (30 мин), остатки по складам WB (30 мин), заказы по регионам (1 час). Если WB не ответил (лимит), показываются последние сохранённые данные с пометкой, а не пустой экран | Серверные маршруты Seller Hub |
| `seller_hub_user_settings` | Настройки: период рекламы (`ads.days`, `ads.compare`), период и параметры плана отгрузки (`logistics.days`, `logistics.coverDays`, `logistics.multiple`). Ключи и значения проверяются по белому списку (`user-settings.ts`) | Пользователь через `/api/seller-hub/user-settings` |
| `seller_hub_agent_rules` | Правила агентов (реклама, цены, ответы, остатки): режим «предлагать» или «автопилот», параметры, включено. По умолчанию выключены | Пользователь (интерфейс правил появится следующим шагом) |
| `seller_hub_agent_actions` | Журнал действий агентов и ручных действий с рекламой и ценами | Сервер и пользователь |
| `seller_hub_warehouse_settings` | Деактивация складов WB и исключение их остатков с даты | Пользователь (интерфейс складов появится следующим шагом) |

Как работает кэш: маршрут сначала смотрит `seller_hub_data_cache`; если запись свежая, WB не трогаем. Кнопка «Обновить» просит свежие данные, но сервер не пускает к WB чаще раза в минуту. Это убирает ошибки 429 при перезагрузках и работает одинаково на всех устройствах.

Что можно переносить дальше: статистика рекламы по дням для долгих периодов и сравнения (чтобы строить динамику старше 30 дней, которые WB отдаёт ограниченно), история остатков по складам (для «дней наличия» и оборачиваемости по складам), снимок задач и событий уже в Supabase.
