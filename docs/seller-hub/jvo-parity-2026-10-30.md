## Что у нас уже на уровне JVO или сильнее
| JVO | У нас |
|---|---|
| Задача простыми словами, уточняющие вопросы, затем план | Чат «Поставить задачу ИИ-менеджеру»: вопросы, затем планы по товарам (проверено 30.10 на «освободить деньги из залежавшегося», «почему падают заказы», «поднять маржу») |
| Сценарии цен С1–С4, П1–П6, Ск1–Ск9 | Не набор жёстких форм, а план ИИ на 1–10 шагов с опорой на справочник решений (`solution-playbook.ts`), с ограничителями: пол безубыточности +5%, шаг до 5%, пауза сутки, общий предел 10% |
| Режим ручного подтверждения | Все действия по кнопке «Выполнить»; автопилот только для безопасных шагов и выключен по умолчанию |
| История каждого действия | Журнал действий + «История работы ИИ» |
| Эффект | Таблица «было → стало» по метрикам плана, контрольные точки, честное «не сработало» и новое решение с историей попыток |
| Минимальная цена | Считается из безубыточности; плюс постоянные правила владельца (нижняя маржа, запрет областей) |
| Ответы на отзывы | Отдельный модуль «Автоответы», вход на странице «Агенты» |
| Реклама: пауза, убрать товар, пополнение, ставка, минус-фразы, места показа | Есть как шаги плана, проверяются по данным кампаний |
| Акции WB, скидка Клуба | Есть как шаги плана (в живом кабинете не проверены: нет управляемых акций) |
| Карточка: заголовок, описание, характеристики | Шаги плана с проверкой текста по правилам WB; без фото и тегов |

## Чего у нас нет или хуже
| Функция JVO | Статус | Решение |
|---|---|---|
| Биддер раз в 5 минут | Нет. Данные раз в 15 минут, ставки меняются шагами плана | Не нужен до запуска рекламных планов в бою; вернуться после проверки на живой кампании |
| Дневной лимит кампании | Нет в плане. В WB метод изменился (`PUT /api/advert/v0/daily-limits`), вживую не проверялся | Добавить после пробы на тестовой кампании |
| Расписание показов, тест позиций, тест ставки с откатом | Нет | Откладываем: выигрыш нужно доказывать на реальных кампаниях |
| Исключение кластеров | Ручной экран «Кластеры» есть, шага плана нет | Минус-фразы закрывают основную часть |
| Массовое создание и импорт кампаний | Нет | Откладываем |
| Готовые шаблоны-стратегии С1–С4 кнопкой | Нет, ИИ собирает план сам | Принято решением Эрика: гибкость важнее шаблонов |
| Расписание запуска сценария «каждый день» | Планы живут до результата и пересматриваются фоном; регулярных повторов нет | Автопилот и фоновый пересчёт закрывают |
| E-mail/Telegram-уведомления | Нет | Telegram в самом конце, по решению владельца |

## Что исправлено 30.10 по итогам прогонов
- В цифрах плана клиент видел имена полей (`cart_pct = 5`): теперь подписи словами.
- В тексте диагноза и шагов встречались `decline_days`, `cart_to_order_pct`: заменяются словами программой, а ИИ в подсказке просят так не писать.
- Текст шага обрезался посреди слова («кол», «сохра»): теперь режется по границе слова с многоточием, лимит шага 600 знаков.
- Служебная пометка `flow: "visual"` попадала в текст шага: вычищается.
- Постоянные правила владельца (раздел «Агенты»: «Правила для ИИ-менеджера»): запрет менять цены, рекламу, карточки и нижняя маржа; программа вычёркивает запрещённые шаги и добавляет ограничитель маржи после ответа ИИ.
- Автоответы стали заметны: отдельная карточка на странице «Агенты».

## Известные ограничения
- Правила владельца действуют на новые планы. Шаги человека с запрещённой областью (например «перепиши заголовок» при запрете карточек) программа не распознаёт, их удерживает только подсказка ИИ.
- Ответ ИИ-менеджера на задачу занимает до минуты и стоит денег ИИ (внутренняя статья, клиенту не показывается).

## Дополнение 31.10.2026
- **Дневной лимит кампании** реализован как действие плана (`ads_daily_limit`) и кнопка «Выполнить»: PUT `/api/advert/v0/daily-limits`, чтение до и после записи, откат прежним значением. Работает только у кампаний с оплатой за клики. Живая проверка: WB отвечает «daily limit is not available for CPM campaigns» на обе кампании Эрика (обе CPM), поэтому запись вживую не проверена; форма запроса совпадает с чтением лимитов, которое уже работает.
- **Регулярные задачи автопилота**: минус-фразы раз в сутки, защита бюджета (пауза и вывод товара из кампании по предложениям рекламного агента), автопополнение бюджета. Каждая включается отдельно, работает только при включённом автопилоте и в суточных пределах.
- **Настройки агентов**: запрет областей, нижняя маржа, запас над безубыточностью (от 5%), шаг цены (до 5%), пауза между изменениями (от 24 ч). Все ограничители только строже стандартных.
