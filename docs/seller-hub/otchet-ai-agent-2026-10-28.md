# Отчёт: что сделано по ИИ-агенту (28.10.2026)

Всё локально. На сайт ничего не выкладывали, в git не отправляли, в кабинете Wildberries ничего не менялось. Деньги и карточки трогает только кнопка «Выполнить» владельца.

## Идея системы
1. **Алгоритмы** (фон каждые 15 минут, задачи, события) постоянно наблюдают за кабинетом и находят сигналы.
2. **ИИ** получает сигналы по товару вместе с картиной всего кабинета и составляет **одно решение на товар**: диагноз, цель с числами, план по дням, контрольные точки, критерии успеха, что не должно ухудшиться, запасной план. Форма решения любая: от одного шага до десяти, сроки до 60 дней.
3. **Второй ИИ** независимо проверяет план. Остановить он может только конкретные шаги с проблемой.
4. **Программа** проверяет цифры и границы, считает цены и ставки, после «Принять» ведёт план по дням, показывает «было → стало» и сама решает: сработало, не сработало (тогда ИИ предлагает другой подход) или наблюдение.

## Что появилось
- **Модели** (по замеру на 13 случаях): аналитик `openai/gpt-5.6-luna`, проверяющий `anthropic/claude-haiku-5.5`; настройка через переменные `SELLER_HUB_AGENT_ANALYST_MODEL` и `SELLER_HUB_AGENT_REVIEWER_MODEL`.
- **Бюджет (внутренний):** месячный потолок $3 на кабинет (`SELLER_HUB_AI_MONTH_CAP_USD`), учёт в базе; клиенту суммы не показываются.
- **Решения по сигналам** («Задачи» → «Что заметил ИИ»): несколько сигналов одного товара сводятся в одно решение.
- **Чат «Поставить задачу ИИ-менеджеру»** («Агенты», вверху): пишешь цель, ИИ задаёт до трёх вопросов за раунд (до двух раундов), выбирает до 6 товаров и составляет план по каждому. Занимает около 45 секунд, около $0.02.
- **Действия, которые выполняет программа после твоего подтверждения:** цена на ступень 1–3%; реклама: пауза, запуск, ставка на 5–20%, тестовая кампания; правка названия и описания карточки (с показом «Было / Станет» и откатом); выход товара из акции WB (вернуть можно только вручную на странице акции). Остальное в плане делает человек.
- **Защиты:** цены не ниже безубыточной, не чаще раза в сутки, общий предел 10%; ставка не больше чем в 3 раза за раз; текст карточки без ссылок, телефонов и рекламных слов, только факты из карточки; цифры ИИ сверяются с данными; шаги программы остаются только после проверки вторым ИИ.
- **История работы ИИ** («Агенты», под чатом): судьба принятых планов с эффектом «было → стало» и исполнением шагов. Расходы на ИИ клиенту не показываются.
- **Шаги человека:** у принятого плана кнопки «Сделал» и «Пропустить» для шагов, на которые у нас нет влияния; программа учитывает исполнение при оценке результата.

## Что не сделано
- Вход в акции WB, поставки и остатки как действия плана (выход из акции сделан; сейчас в твоём кабинете нет товаров в управляемых акциях, поэтому проверен тестами, не вживую).
- Автопилот (шаги без кнопки по правилам владельца).
- Реальные правки текстов карточек проверить после выкладки: нужны значения характеристик в данных (приходят после синхронизации сервера).
- Рамки владельца (бюджет осознанного убытка).
