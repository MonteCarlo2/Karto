# Агенты: сверка с JVO по их справочнику (28.10.2026)

Источники по JVO: страницы справочного центра jvo.ru/help (JVO Агент, Сценарии, Умное изменение цен, Сценарии цен, Агент рекламы, готовые запросы по продажам, отзывам, складу, комплексные стратегии). Скрытые раскрывающиеся блоки и пороги внутри их интерфейса нам недоступны. Ниже: что есть у JVO и что у нас.

## Общее устройство агента
| Функция JVO | У нас |
|---|---|
| Задача простыми словами, вопросы агента, сценарий | Чат ИИ-менеджера; область задачи (товар, группа, магазин) выясняется вопросом; план на 1–10 шагов; сводка «Итог перед запуском» |
| Ручное подтверждение или автоматический режим | Кнопка «Выполнить» у каждого действия; автопилот: правила владельца, переключатель у плана, безопасные типы, суточные пределы |
| Расписание: один раз или регулярно | Запуск плана сразу или позже (дата и время), «Предложить шаг сейчас», шаги-триггеры «если …» (проверка раз в 10 минут), регулярные задачи автопилота (минус-фразы, защита бюджета, автопополнение, проверка акций, недельный отчёт) |
| Проверка до запуска, симуляция | Второй ИИ проверяет, решает ли план задачу; до двух доработок; «было → станет» у каждого ценового предложения |
| Минимальная цена обязательна | Пол: безубыточность + запас (по умолчанию 5%, владелец может только поднять), шаг до 5%, пауза от 24 ч, общий предел 10% |
| История каждого действия, события | Журнал действий (кто, что, результат), «История работы ИИ», недельный отчёт, «было → стало» по плану |
| Пропуск шага при нехватке данных | Шаг-триггер без данных ждёт; ограничитель нарушен: план останавливается |
| Конфликты между правилами | Одно ценовое действие за раз и не чаще раза в сутки; общий предел; запрещённые области владельца вычёркиваются программой |

## Цена
| JVO | У нас |
|---|---|
| Сценарии С1–С4, П1–П6, Ск1–Ск9 (рост/падение спроса, оборачиваемость, конверсия в корзину, поставка, негатив, неликвид) | Не жёсткие формы, а план ИИ по словарю типовых задач (`TASK_GLOSSARY`) и справочнику решений; те же рычаги: цена вверх/вниз малыми шагами с триггерами по остатку, оборачиваемости, конверсии, дням падения и роста заказов |
| Скидка продавца или базовая цена как параметр | Цена для покупателя через скидку продавца; скидка WB Клуба; вход и выход из акций |
| Учёт СПП и Клуба в минимальной цене | Клуб учитывается; СПП в API нет |

## Реклама
| JVO | У нас |
|---|---|
| Пауза/запуск, убрать артикул, ставка, пополнение, автопополнение, дневной лимит | Все есть как шаги плана; дневной лимит (только оплата за клики); автопополнение регулярной задачей в пределах суммы |
| Минус-фразы/исключение кластеров (правило 100 показов) | Минус-фразы только из реальных запросов кластера товара (WB не принимает иные); регулярная задача раз в сутки; автопилот |
| Метрики ДРР, CPO, CTR, конверсия | Теперь входят в данные агента и критерии планов: ads_drr, ads_cpo, ads_orders, расход, CTR (раньше агент их не видел) |
| Тест ставки с откатом | Шаг повышения + шаг возврата с условием «если заказы с рекламы не выросли» или «ДРР выше порога» |
| Пять стратегий (защита бюджета, лучшая позиция, масштабирование) | Словарные задачи «защити бюджет», «протестируй ставку с откатом», «масштабируй, пока окупается» |
| Создание кампаний, массовый импорт | Тестовая кампания шагом плана; полное создание в разделе «Продвижение»; существующие кампании читаются сами |
| Расписание показов, тепловая карта | Нет: в публичном API WB метода расписания нет |
| Поиск лучшей позиции (перебор топ-10) | Нет: нужна динамика позиций по кластерам и цикл раз в 5 минут; данные раз в 10–15 минут. Решение владельца: кластеры не нужны |

## Отзывы и бренд
Ответы на отзывы и вопросы живут отдельным модулем «Автоответы» (вход со страницы «Агенты»). Допродажа в ответах: задача «Допродавай товары» ведёт в автоответы с перечнем товаров-пар. Нет у нас: R&D-отчёт по причинам отказов из последних 500 отзывов (можно добавить отдельным разбором).

## Склад и поставки
JVO: цена как рычаг остатка и Логистика PRO («сформировать отгрузку»). У нас: цена по остатку и оборачиваемости с триггерами, раздел «Заказы и логистика», рекомендации по поставке шагом человека (решение владельца: поставки и остатки FBS делает человек).

## Что осталось и почему
- Расписание показов и тепловая карта: нет метода в API.
- Перебор позиций и 5-минутный биддер: другой класс продукта, решение владельца.
- R&D-отчёт по отзывам: возможен, не сделан.
- Джем: чтение подписки требует токен типа «Сервисный».
- Реальная проверка записи дневного лимита и работы акций: у владельца нет кампаний с оплатой за клики и управляемых акций.
